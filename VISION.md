# jira-axi v1

jra-axi is Jira Cloud only (`*.atlassian.net`). REST v3 covers Jira resources. Agile 1.0 covers boards and sprints.

The v1 command surface includes accounts, auth, issues, projects, boards, sprints, users, home, TUI, skill, and setup hooks.

Issues covers list, view, create, update, assign, transition, comment, link, worklog, and meta.

## Out of scope for v1

- Attachment upload and download
- Watchers
- Bulk edit and transition
- Issue delete
- Changelog and history
- Saved filters
- Webhooks
- Jira Service Management
- Jira Data Center and Server
- OAuth 3LO login
- Admin field create and delete
